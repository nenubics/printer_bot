# 🛡️ Руководство по защите от атак КИИБ (Харденинг: Бот, Роутер Huawei AX3, Принтер Pantum BP2300NW)

В условиях студенческого общежития с проживанием студентов профиля **КИИБ (Комплексная информационная безопасность)** сервис печати является привлекательной целью для взлома, бесплатной печати в обход бота, переполнения ресурсов и вывода оборудования из строя.

Данный документ описывает комплекс мер трехуровневой эшелонированной обороны (**Defense in Depth**).

---

## 🏗 Архитектура безопасности: «Нулевое доверие» (Zero-Trust)

```
[ Студенты (КИИБ) ] 
       │
       ▼ (Только через защищенный Telegram Bot API)
┌──────────────────────────────────────────────────────────┐
│  Сервер Бота (Raspberry Pi / Linux / Docker)             │
│  - Адаптивный бан за флуд (Throttling)                   │
│  - Квоты на заказы (макс 3) и депозиты (макс 2)          │
│  - Проверка magic bytes, санитизация PDF, отсев скриптов │
│  - Контроль свободного диска (>500 МБ)                   │
│  - Права файлов: БД 0600, спул 0700                      │
└──────────────────────────────────────────────────────────┘
       │
       ▼ (Внутренняя закрытая подсеть или прямой Ethernet)
┌──────────────────────────────────────────────────────────┐
│  Wi-Fi Роутер Huawei AX3                                 │
│  - WPS отключен (защита от Reaver/Pixie Dust)            │
│  - UPnP отключен (защита от проброса портов)             │
│  - Изоляция клиентов (AP Isolation)                      │
│  - Отдельный скрытый SSID для инфраструктуры печати      │
└──────────────────────────────────────────────────────────┘
       │
       ▼ (Порт 9100 / RAW Socket)
┌──────────────────────────────────────────────────────────┐
│  Принтер Pantum BP2300NW                                 │
│  - Сменен заводской пароль web-панели                    │
│  - IP-фильтрация (ACL): разрешен ТОЛЬКО IP сервера бота  │
│  - Отключены AirPrint, Bonjour, mDNS, WSD                │
│  - Отключен или защищен SNMP (порт 161)                  │
└──────────────────────────────────────────────────────────┘
```

## 1. 📡 Настройка роутера Huawei WiFi AX3

Роутер Huawei AX3 — первый рубеж сетевой обороны. Если не закрыть сеть, студенты найдут принтер через `nmap` и отправят печать напрямую.

### 1.1. Отключение WPS (Wi-Fi Protected Setup) — КРИТИЧЕСКИ ВАЖНО!
> ⚠️ **Уязвимость**: Студенты КИИБ могут использовать утилиты `reaver` или `bully` (атака Pixie Dust) для подбора 8-значного WPS PIN-кода за несколько минут, получив пароль от Wi-Fi.
- **Действие**:
  1. Войдите в панель управления роутером: `http://192.168.3.1`
  2. Перейдите: **Дополнительные функции** (More Functions) ➔ **Настройки Wi-Fi** (Wi-Fi Settings) ➔ **WPS**.
  3. Переведите переключатель **WPS** в положение **Выключено (Off)**.

### 1.2. Создание изолированной сети (Dedicated Hidden SSID)
> ⚠️ **Уязвимость**: Если студенты знают пароль от Wi-Fi, к которому подключен принтер, они находятся в одном широковещательном домене.
- **Действие**:
  - Создайте отдельную сеть (или гостевую сеть с изоляцией) **только** для принтера и сервера бота.
  - **Шифрование**: только `WPA2-PSK (AES)` или `WPA3-SAE`.
  - **Пароль**: не менее 24 случайных символов (буквы разного регистра, цифры, спецсимволы).
  - Скройте имя сети (Hide SSID): студенты даже не увидят сеть в списке доступных.
  - **Никому не сообщайте пароль от этой сети**. Студентам он не нужен, так как они отправляют файлы через Telegram.

### 1.3. Включение изоляции клиентов (AP Isolation)
> ⚠️ **Уязвимость**: Взлом соседних устройств, ARP-спуфинг (`arpspoof`, `bettercap`) для перехвата незашифрованного трафика печати.
- **Действие**:
  - В настройках Wi-Fi включите параметр **Изоляция точек доступа / AP Isolation**.
  - Теперь беспроводные клиенты не могут сканировать и отправлять пакеты друг другу.

### 1.4. Отключение UPnP и удаленного доступа к роутеру
- **UPnP**: **Дополнительные функции** ➔ **Настройки безопасности** ➔ **UPnP** ➔ **Выключить**. Это предотвращает автоматическое открытие портов наружу.
- **Удаленный доступ (WAN)**: Убедитесь, что доступ к веб-панели управления со стороны WAN-порта (внешней сети общаги) строго **отключен**.
- **Пароль администратора роутера**: Установите надежный пароль длиной от 16 символов, отличный от пароля Wi-Fi.

## 2. 🖨 Настройка принтера Pantum BP2300NW

Pantum BP2300NW оснащен собственным сетевым контроллером. По умолчанию он максимально открыт для удобства пользователей, что в условиях общаги недопустимо.

### 2.1. Смена заводского пароля Web-интерфейса
> ⚠️ **Уязвимость**: По умолчанию логин/пароль веб-панели Pantum — `admin` / `000000` (или `admin` / `admin`). Любой студент может сбросить настройки или заблокировать принтер.
- **Действие**:
  1. Откройте в браузере `http://<IP_ПРИНТЕРА>` (например, `http://192.168.3.100`).
  2. Войдите с текущим паролем.
  3. Перейдите в **Управление учетными записями / Безопасность**.
  4. Задайте сложный административный пароль (не менее 16 символов).

### 2.2. Аппаратная IP-фильтрация (Access Control List) — ГЛАВНЫЙ ЩИТ!
> ⚠️ **Уязвимость**: Прямая печать через RAW 9100 (`nc 192.168.3.100 9100 < document.pdf`) в обход бота и оплаты.
- **Действие**:
  1. В веб-интерфейсе Pantum перейдите в **Настройки сети (Network Settings)** ➔ **IP-фильтр (IP Filter / Access Control)**.
  2. Включите IP-фильтрацию.
  3. Добавьте правило: **Разрешить ТОЛЬКО IP-адрес сервера с ботом** (например, `192.168.3.50`).
  4. Для всех остальных IP-адресов — **Запретить (Drop / Deny)**.
  5. *Результат*: Сетевая карта принтера на аппаратном уровне сбрасывает любые TCP-соединения со всех устройств, кроме сервера бота! Прямая печать мимо бота становится физически невозможной.

### 2.3. Отключение автообнаружения (AirPrint, Bonjour, mDNS, WSD)
> ⚠️ **Уязвимость**: По умолчанию Pantum анонсирует себя в эфир. Смартфоны студентов (iPhone/Android) автоматически находят принтер в шторке и предлагают распечатать документ без Telegram.
- **Действие**:
  - В разделе **Настройки протоколов (Network Protocols)** отключите:
    - ❌ **Bonjour / mDNS**
    - ❌ **AirPrint**
    - ❌ **WS-Discovery (WSD)**
    - ❌ **IPP (порт 631)** — если используется RAW-сокет 9100
  - *Результат*: Принтер становится «невидимкой» для устройств Apple, Android и Windows.

### 2.4. Защита или отключение SNMP (порт 161)
> ⚠️ **Уязвимость**: Дефолтная строка сообщества `public` позволяет утилитам `snmpwalk` считывать статистику, серийный номер, количество отпечатков и сетевую конфигурацию.
- **Действие**:
  - Отключите службу SNMP, либо измените community strings `public` и `private` на сложные случайные токены.

## 3. 🤖 Защита сервера бота (Уровень приложения и ОС)

В боте реализованы программные рубежи против атак на приложение:

| Вектор атаки КИИБ | Как реализована защита в боте |
| :--- | :--- |
| **Флуд скриптами (Anti-DoS)** | `ThrottlingMiddleware` с адаптивным штрафным баном: 5 частых запросов вызывают блокировку аккаунта на 30 секунд. Сообщения бота не генерируют ответов флудерам. |
| **Переполнение диска (Spool DoS)** | Лимит: максимум `MAX_PENDING_ORDERS_PER_USER = 3` активных неоплаченных заказа на студента. Проверка `MIN_FREE_DISK_MB = 500`: при нехватке места прием файлов блокируется. |
| **Брошенные файлы в спуле** | Фоновый спулер каждые 60 секунд проверяет и автоматически удаляет с диска неоплаченные файлы старше 2 часов. |
| **Спам чеками СБП в чат админа** | Лимит: максимум `MAX_PENDING_DEPOSITS_PER_USER = 2` открытых заявок на пополнение. Валидация файлов чеков: только фото или PDF до 5 МБ. Бинарники, скрипты, HTML и SVG блокируются. |
| **Фальсификация сумм в callback** | Сервер не доверяет строкам из кнопок: суммы списания и пополнения берутся **строго из БД** (`order.cost_rub`, `tx.amount`). |
| **Атака на права файлов** | База данных создается с правами `0600`, папки `data/` и `data/spool/` — с правами `0700`. Непривилегированные пользователи хоста не могут прочесть БД или чужие файлы печати. |
| **Атаки на парсер PDF (CVE/RCE)** | `pypdf.PdfWriter` физически пересобирает страницы, полностью удаляя встроенный исполняемый JavaScript, Launch Actions и опасные объекты перед отправкой на принтер. |

## 4. 🐧 Настройка фаервола Linux (UFW / Iptables)

Если бот запущен на выделенном сервере (Raspberry Pi или мини-ПК):

```bash
# Разрешаем только исходящие соединения к Telegram API и принтеру
sudo ufw default deny incoming
sudo ufw default allow outgoing

# Разрешаем SSH только с доверенного IP администратора (по ключам)
sudo ufw allow from 192.168.3.X to any port 22 proto tcp

# Включаем фаервол
sudo ufw enable
```

Для регулярной проверки целостности всех механизмов защиты запустите встроенный скрипт аудита:
