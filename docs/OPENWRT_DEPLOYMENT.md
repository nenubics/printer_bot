# Руководство по развертыванию на OpenWrt и слабых устройствах (Netis NX31, Huawei AX3, MIPS/ARM)

Настоящее руководство описывает запуск и эксплуатацию Telegram-бота `printer_bot` на сверхмаломощных сетевых устройствах с оперативной памятью от **128 до 256 МБ ОЗУ** и ограниченным объемом флеш-памяти.

---

## 1. Поддерживаемое аппаратное обеспечение

| Устройство | Процессор / Архитектура | Оперативная память (RAM) | Накопитель (Flash) | Особенности / Статус |
| :--- | :--- | :--- | :--- | :--- |
| **Netis NX31** | MediaTek MT7981B (Filogic 820) Cortex-A53 (2 ядра @ 1.3GHz) | 256 MB DDR3 | 128 MB SPI NAND | **Идеальная платформа**. OpenWrt 23.05+, отличная скорость. |
| **Netis NX31 (MIPS rev)** | MediaTek MT7621A MIPS 1004Kc (2 ядра / 4 потока @ 880MHz) | 128 MB / 256 MB DDR3 | 16/32 MB SPI NOR | Требуется включение `zram-swap` и `LOW_MEMORY_MODE=true`. |
| **Huawei AX3 (WS7100 / WS7200)** | Gigahome Hi5651L/T Cortex-A53 | 128 MB / 256 MB RAM | 128 MB NAND | Работа через Entware или прошивку OpenWrt; прямое подключение к Pantum. |
| **Raspberry Pi Zero W / Orange Pi Zero** | ARM11 / Allwinner H2+ / H3 | 256 MB / 512 MB | MicroSD (Class 10) | Стабильная работа в нативном Linux/DietPi. |

## 2. Реализованные аппаратные оптимизации

### 2.1. Потоковый рендеринг документов \(O(1)\) по RAM
* **Проблема:** Классический рендеринг документа на 10 страниц при 300 DPI держит в памяти 10 некомпрессированных растровых холстов ($10 \times 8.7\text{ МБ} = 87\text{ МБ}$), что приводит к гарантированному вызову `OOM Killer` на роутере.
* **Решение:** Внедрен пошаговый потоковый пайплайн. В памяти всегда находится **ровно один лист** ($2.1\text{ МБ}$ при 150 DPI). После добавления страницы во временный поток `pypdf.PdfWriter` объект `Image` удаляется, а сборщик мусора `gc.collect()` освобождает страницы памяти ядру Linux.

### 2.2. Адаптивное разрешение и билинейная фильтрация
* В режиме `LOW_MEMORY_MODE=true` разрешение рендеринга A4 автоматически устанавливается в **150 DPI** ($1240 \times 1754$ px).
* Потребление памяти снижается ровно в **4 раза** по сравнению с 300 DPI.
* Фильтрация `BILINEAR` заменяет `LANCZOS`, экономя миллионы тактов процессора на процессорах без инструкций NEON/SIMD (MIPS MT7621).
* При этом для монохромного лазерного принтера Pantum BP2300NW текст остается четким и контрастным благодаря интеллектуальному отбеливанию фона (`enhance_document_image`).

### 2.3. Защита флеш-памяти (Flash Wear Protection)
* Флеш-память роутера (NAND/NOR) быстро изнашивается при постоянной перезаписи временных PDF-файлов.
* Бот автоматически определяет роутер и перенаправляет спул в **RAM-диск `tmpfs`** (`/tmp/printer_bot_spool`), где файлы хранятся исключительно в оперативной памяти и не вызывают деградации кремния роутера.

### 2.4. Тонкая настройка SQLite PRAGMA
* `cache_size = -2000` (2 МБ кэша страниц вместо 64 МБ десктопных).
* `mmap_size = 0` (отключение отображения файлов в память исключает фрагментацию 32-битного адресного пространства на MIPS и панику ядра).
* `temp_store = FILE` (сортировки и индексы не отнимают оперативную память).
* `wal_autocheckpoint = 100` (частый сброс WAL-лога предотвращает разрастание базы).

### 2.5. Потоковая печать RAW Socket (Port 9100)
* На роутерах отсутствует тяжелый стек CUPS (`cupsd`, `ghostscript`, `foomatic`), который весит более 100 МБ.
* Печать выполняется напрямую по протоколу JetDirect/RAW через TCP-порт **9100** принтера Pantum BP2300NW.
* Файлы передаются чанками по **64 КБ**, не требуя выделения дополнительных буферов в ОЗУ.

## 3. Пошаговая установка на OpenWrt (Netis NX31)

### Шаг 1: Подключение к роутеру по SSH
```bash
ssh root@192.168.1.1
```

### Шаг 2: Установка системных пакетов
```bash
opkg update
opkg install python3 python3-pip python3-pillow python3-asyncio libsqlite3 ca-bundle zram-swap
```

### Шаг 3: Активация ZRAM Swap (Критично для устройств со 128-256 МБ RAM!)
ZRAM создает виртуальный сжатый swap в оперативной памяти со степенью сжатия ~2.5:1. Это превращает 60 МБ свободной RAM в дополнительные **150 МБ** виртуальной памяти:
```bash
/etc/init.d/zram start
/etc/init.d/zram enable
# Проверка:
free -m
```

### Шаг 4: Копирование бота и установка Python библиотек
Скопируйте проект в `/opt/printer_bot` (или на подключенную USB-флешку `/mnt/sda1/printer_bot`):
```bash
mkdir -p /opt/printer_bot
cd /opt/printer_bot

# Установка Python-зависимостей без кэширования колес:
pip3 install --no-cache-dir \
    "aiogram>=3.17.0" \
    "pydantic>=2.10.0" \
    "pydantic-settings>=2.7.0" \
    "aiosqlite>=0.21.0" \
    "sqlalchemy>=2.0.38" \
    "pypdf>=5.3.0" \
    "qrcode>=8.0"
```

### Шаг 5: Настройка конфигурации `.env`
Создайте файл `/opt/printer_bot/.env`:
```env
BOT_TOKEN=1234567890:AAHxxxxxx_ваш_токен_бота_здесь
ADMIN_IDS=[123456789]

# Режим для роутера
LOW_MEMORY_MODE=true
RENDER_DPI=150
FLASH_PROTECTION_MODE=true
SPOOL_DIR=/tmp/printer_bot_spool

# Сетевой принтер Pantum BP2300NW
PRINTER_MODE=raw
PRINTER_HOST=192.168.3.13
PRINTER_PORT=9100

# Лимиты для роутера
MAX_FILE_SIZE_BYTES=15728640
MAX_PAGES_PER_JOB=40
MIN_FREE_DISK_MB=25

# Экономия бумаги и тонера
AUTO_SKIP_BLANK_PAGES=true
ENHANCE_CONTRAST_PHOTOS=true
```

### Шаг 6: Установка системной службы автозапуска `procd`
Скопируйте скрипт инициализации:
```bash
cp /opt/printer_bot/deploy/openwrt/printer_bot.init /etc/init.d/printer_bot
chmod +x /etc/init.d/printer_bot
/etc/init.d/printer_bot enable
/etc/init.d/printer_bot start
```

## 4. Диагностика и мониторинг

### Проверка статуса сервиса
```bash
/etc/init.d/printer_bot status
```

```bash
logread -f -e printer_bot
```

```bash
top -b -n 1 | grep python3

free -m
```

## 5. Специфика Huawei AX3 (WS7100 / WS7200)

* Роутеры Huawei AX3 со стоковой прошивкой обычно не имеют открытого доступа к SSH без специальной разблокировки.
* **Рекомендуемый сценарий интеграции:**
  1. Huawei AX3 работает в режиме мощной двухдиапазонной Wi-Fi 6 точки доступа (AP / Bridge).
  2. Принтер Pantum BP2300NW подключен к Huawei AX3 по Wi-Fi или патч-кордом в LAN-порт (`192.168.3.13`).
  3. Бот запускается на роутере Netis NX31, ТВ-приставке или микро-сервере в той же локальной сети и отправляет задания печати на IP принтера без посредников.
  4. Если на Huawei AX3 установлен кастомный Linux или Entware, бот развертывается по аналогии с разделом 3 в директорию `/opt`.
