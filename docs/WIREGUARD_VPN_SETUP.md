# 🌐 Архитектура: Облачный VPS + VPN-роутер Xiaomi AX3000T (OpenWrt) + Pantum BP2300NW

Данное руководство описывает профессиональную топологию развертывания бота печати, при которой **сам бот и база данных работают на недорогом облачном VPS**, а доставка заданий на принтер в общежитии ЦСО-4 осуществляется через зашифрованный **Site-to-Site WireGuard туннель** на базе роутера **Xiaomi AX3000T с OpenWrt**.

---

## 🛡 Преимущества схемы перед локальным сервером

1. **Абсолютная неуязвимость перед соседями-безопасниками (КИИБ)**:
   - Сервер бота физически находится в дата-центре. В локальной сети общежития **нет сервера**, который можно попытаться взломать через сканирование портов, брутфорс SSH или ARP-спуфинг.
2. **Стабильность 24/7**:
   - Облачный VPS не зависит от выбитых пробок в комнате, моргания света или отключения роутера жильцами.
3. **Обход провайдерского NAT общежития**:
   - Роутер Xiaomi AX3000T сам инициирует постоянное исходящее соединение с VPS. Поэтому серый IP провайдера общаги больше не проблема.
4. **Легковесность для Xiaomi AX3000T**:
   - Процессор роутера не нагружается Python, Pillow и тяжелой нарезкой PDF. Роутер просто пересылает несколько килобайт потока RAW-печати по сокету.

## 🚀 Быстрая автоматическая настройка (1 кнопка)

### Шаг 1. На облачном VPS (Ubuntu / Debian)

Клонируйте репозиторий на VPS и запустите готовый скрипт автоматической настройки:

```bash
git clone git@github.com:nenubics/printer_bot.git
cd printer_bot
sudo bash scripts/setup_wireguard_vps.sh
```

Скрипт автоматически:
1. Установит `wireguard` и `iptables`.
2. Включит IP forwarding в ядре Linux.
3. Сгенерирует надежные ключи шифрования (Curve25519).
4. Настроит `/etc/wireguard/wg0.conf` с маршрутом к принтеру `192.168.3.100`.
5. Запустит службу `wg-quick@wg0`.
6. **Выдаст на экран готовый блок команд для вставки в OpenWrt на Xiaomi AX3000T!**

## 🛠 Ручная настройка на Xiaomi AX3000T (OpenWrt)

### Вариант А: Через SSH консоль роутера (быстрее всего)

Подключитесь к AX3000T по SSH:
```bash
ssh root@192.168.3.1
```

Выполните команды (подставив ключи и IP вашего VPS, выданные скриптом):

```bash
# 1. Установка пакетов WireGuard (если не были установлены ранее)
opkg update
opkg install luci-proto-wireguard kmod-wireguard wireguard-tools

# 2. Создание сетевого интерфейса wg0
uci set network.wg0=interface
uci set network.wg0.proto='wireguard'
uci set network.wg0.private_key='<ПРИВАТНЫЙ_КЛЮЧ_РОУТЕРА>'
uci add_list network.wg0.addresses='10.0.0.2/24'

# 3. Настройка подключения к VPS
uci set network.wgserver=wireguard_wg0
uci set network.wgserver.public_key='<ПУБЛИЧНЫЙ_КЛЮЧ_СЕРВЕРА_VPS>'
uci set network.wgserver.endpoint_host='<ПУБЛИЧНЫЙ_IP_VPS>'
uci set network.wgserver.endpoint_port='51820'
uci set network.wgserver.persistent_keepalive='25'
uci add_list network.wgserver.allowed_ips='10.0.0.0/24'

# 4. Добавление интерфейса wg0 в зону LAN (чтобы пакеты печати шли на принтер)
uci add_list firewall.@zone[0].network='wg0'

# 5. Применение настроек
uci commit
/etc/init.d/network restart
/etc/init.d/firewall restart
```

---

### Вариант Б: Через веб-интерфейс LuCI

1. Откройте веб-панель OpenWrt в браузере: `http://192.168.3.1`
2. Перейдите: **Network** ➔ **Interfaces** ➔ нажмите **Add new interface...**:
   - **Name**: `wg0`
   - **Protocol**: `WireGuard VPN`
   - Нажмите **Create interface**.
3. Во вкладке **General Settings**:
   - **Private Key**: укажите приватный ключ роутера.
   - **IP Addresses**: `10.0.0.2/24`
4. Во вкладке **Peers** нажмите **Add peer**:
   - **Public Key**: публичный ключ сервера VPS.
   - **Endpoint host**: внешний IP-адрес вашего VPS.
   - **Endpoint port**: `51820`
   - **Allowed IPs**: `10.0.0.0/24`
   - **Persistent Keep Alive**: `25` (обязательно! удерживает NAT открытым).
5. Во вкладке **Firewall Settings**:
   - Назначьте интерфейс в зону **`lan`**.
6. Нажмите **Save & Apply**.

## 🔍 Проверка работоспособности туннеля

На сервере VPS выполните проверку соединения:

1. **Проверка статуса WireGuard**:
   ```bash
   sudo wg show
   ```
   В выводе должно быть:
   ```
   peer: <PUBKEY>
     endpoint: <IP_ОБЩАГИ>:<PORT>
     latest handshake: 10 seconds ago
     transfer: 1.2 KiB received, 850 B sent
   ```

2. **Пинг роутера через туннель**:
   ```bash
   ping -c 3 10.0.0.2
   ```

3. **Проверка прямого сетевого сокета принтера Pantum BP2300NW**:
   ```bash
   nc -zv -w 3 192.168.3.100 9100
   ```
   *Вывод `Connection to 192.168.3.100 port 9100 [tcp/jetdirect] succeeded!` означает, что облачный VPS видит принтер в общежитии так же, как если бы стоял рядом на столе.*

## ⚙️ Конфигурация `.env` бота на VPS

В файле `.env` на облачном сервере укажите:

```ini
# Сетевой режим печати через WireGuard туннель
PRINTER_MODE=raw
PRINTER_HOST=192.168.3.100
PRINTER_PORT=9100
PRINTER_NAME=Pantum_BP2300NW
```

Бот на VPS прозрачно отправляет задания печати на `192.168.3.100:9100`, ядро направляет их в туннель `wg0`, Xiaomi AX3000T принимает их и мгновенно передает по кабелю на Pantum BP2300NW.
